# Project 1 — Smart Bed

Svelte mock-up of an interactive smart bed UI.

## Run

```bash
cd proj1
npm install
npm run dev
```

Then open the URL Vite prints (usually http://localhost:5173).

## Level 0

- **Testing UI** (left): project info, bed placement diagram, simulation buttons, info panel
- **Device UI** (right): headboard display + side-rail controls from the homework mock-up
